# Database Sequence Migration Workflow

This document defines the exact execution sequence for migrating database entities and tables from `IDENTITY` to `SEQUENCE` in the TaskPilot platform.

---

## 阶段 Phase 1: Audit & Discovery

1. **Inventory Generation**:
   - Locate all JPA entities annotated with `@Entity`.
   - Distinguish composite primary keys (`@EmbeddedId`, `@IdClass`) from single surrogate keys.
   - For all surrogate keys, record current `@GeneratedValue` strategy, generator names, table names, and matching database sequences.

2. **Schema State Inspection**:
   - Query `pg_class`, `pg_sequences`, and `information_schema.columns` to verify if sequences already exist (e.g. implicitly created via `GENERATED BY DEFAULT AS IDENTITY` or `BIGSERIAL`).
   - Identify column names and current sequence state.

---

## 阶段 Phase 2: Schema Migration (Flyway DDL)

1. **Craft Versioned Migration Script (`V22__migrate_identity_to_sequences.sql`)**:
   - For each table with `IDENTITY` or `BIGSERIAL`:
     ```sql
     -- 1. Ensure dedicated sequence exists
     CREATE SEQUENCE IF NOT EXISTS <table>_id_seq;

     -- 2. Synchronize sequence start/current value with existing table data
     SELECT setval('<table>_id_seq', COALESCE((SELECT MAX(id) FROM <table>), 1));

     -- 3. Drop identity constraint if present (idempotent)
     ALTER TABLE <table> ALTER COLUMN id DROP IDENTITY IF EXISTS;

     -- 4. Assign sequence as column default
     ALTER TABLE <table> ALTER COLUMN id SET DEFAULT nextval('<table>_id_seq');

     -- 5. Set sequence ownership to column
     ALTER SEQUENCE <table>_id_seq OWNED BY <table>.id;
     ```

2. **Idempotency & Re-run Safety**:
   - Ensure `IF NOT EXISTS` and `IF EXISTS` are used throughout.
   - Ensure script executes cleanly on both pristine (empty) databases and populated production databases.

---

## 阶段 Phase 3: JPA Entity Refactoring

1. **Base Superclass Strategy**:
   - Update `BaseEntity`:
     - Retain `@MappedSuperclass` with auditing fields (`createdAt`, `updatedAt`).
     - Remove monolithic `@Id` from `BaseEntity` so each subclass explicitly declares its dedicated `@SequenceGenerator` and `@GeneratedValue(strategy = GenerationType.SEQUENCE, ...)`.
     - Alternatively, define a parameterized or concrete generator pattern per entity.

2. **Concrete Entity Updates**:
   - Apply explicit `@SequenceGenerator` and `@GeneratedValue`:
     ```java
     @Id
     @GeneratedValue(strategy = GenerationType.SEQUENCE, generator = "<table_name>_id_seq_gen")
     @SequenceGenerator(name = "<table_name>_id_seq_gen", sequenceName = "<table_name>_id_seq", allocationSize = 1)
     private Long id;
     ```
   - Target entities:
     - `UserEntity` (`users_id_seq`)
     - `ChatSessionEntity` (`chat_sessions_id_seq`)
     - `RefreshTokenEntity` (`refresh_tokens_id_seq`)
     - `PasswordResetTokenEntity` (`password_reset_tokens_id_seq`)
     - `CommentEntity` (`comments_id_seq`)
     - `ProjectEntity` (`projects_id_seq`)
     - `TaskEntity` (`tasks_id_seq`)
     - `SprintEntity` (`sprints_id_seq`)
     - `LabelEntity` (`labels_id_seq`)
     - `SkillEntity` (`skills_id_seq`)
     - `NotificationEntity` (`notifications_id_seq`)
     - `AiChatRequestEntity` (`ai_chat_requests_id_seq`)
     - `ChatMessageEntity` (`chat_messages_id_seq`)
     - `AiLogEntity` (`ai_logs_id_seq`)

---

## 阶段 Phase 4: Test & Verification

1. **Compilation & Unit Testing**:
   - Compile all modules: `./mvnw clean test-compile`.
   - Run unit test suite: `./mvnw test`.

2. **Persistence & Sequence Validation**:
   - Verify `nextval` behavior when persisting new records.
   - Verify that inserted entity receives expected ID without triggering DB constraint violation.

3. **JDBC Batching Verification**:
   - Verify batch insert capabilities with `hibernate.jdbc.batch_size` configured.
   - Verify logs confirm batched SQL statement execution.

---

## 阶段 Phase 5: Rollback & Recovery Plan

1. **Rollback DDL**:
   - In case of unforeseen rollback, execute:
     ```sql
     ALTER TABLE <table> ALTER COLUMN id DROP DEFAULT;
     ALTER TABLE <table> ALTER COLUMN id ADD GENERATED BY DEFAULT AS IDENTITY;
     ```
2. **Entity Reversion**:
   - Revert `@GeneratedValue(strategy = GenerationType.SEQUENCE)` back to `GenerationType.IDENTITY`.
